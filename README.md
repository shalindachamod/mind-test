# 🧠 Memory Master Game

A modern, interactive, and colorful **Memory Test Game** built using pure HTML, CSS, and JavaScript. Test and improve your short-term memory by repeating increasing patterns of colors and sound tones!

---

## ✨ Features

* **🎮 Multiple Game Modes**:
  * **🏆 Level Challenge**: Complete 25 progressively difficult levels.
  * **♾️ Classic Unlimited**: Endless mode to push your memory limits to the absolute max.
* **🔥 Difficulty Modes**:
  * **🟢 Easy Mode**: Standard 4-color layout (Red, Blue, Green, Yellow).
  * **🔥 Hard Mode**: Challenging 6-color grid layout (Adds Orange & Purple).
* **🎨 Multiple Themes & Dark/Light Toggle**:
  * Themes: **Classic Navy**, **Neon Glow**, **Cyberpunk**.
  * Toggle between **🌙 Dark Mode** and **☀️ Light Mode** seamlessly.
* **🔊 Dynamic Audio Effects**:
  * Custom Web Audio API tones generated per color button (No external MP3 files needed).
  * Dedicated Mute/Unmute (🔊 / 🔇) button in the header.
* **📱 Fully Responsive**: Smooth Glassmorphic UI designed for Mobile, Tablet, and Desktop screens.

---

## 🛠️ Built With

* **HTML5**: Game structure and elements.
* **CSS3**: Custom CSS variables, animations, and Responsive Glassmorphism Design.
* **JavaScript (Vanilla)**: Core game logic, state management, and Fisher-Yates array handling.
* **Web Audio API**: Browser-native sound generation for button flashes and win/lose tones.

---

## 🚀 How to Play

1. **Select Theme & Mode**: Choose your preferred Theme (Classic, Neon, or Cyberpunk) and toggle Dark/Light mode.
2. **Choose Difficulty**: Select between **Easy (4 Colors)** or **Hard (6 Colors)**.
3. **Pick Game Mode**: Click on **Level Challenge** or **Classic Unlimited**.
4. **Watch the Pattern**: Pay close attention as the game flashes a pattern of colors with distinct tones.
5. **Repeat the Sequence**: Click the colored buttons in the exact same order.
6. **Advance & Win**: Each successful round adds a new color to the sequence. Beat all 25 levels in Level Mode to become the Memory Master!
